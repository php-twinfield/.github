# PHP Twinfield has moved

The libraries in this organisation are no longer maintained. Development continues in a new SDK by [SolveBeam](https://www.solvebeam.com/):

## ➡️ [solvebeam/twinfield-php](https://github.com/solvebeam/twinfield-php)

A modern PHP SDK for the Twinfield API, built on PSR standards.

```sh
composer require solvebeam/twinfield
```

- [Documentation](https://php.twinfield.solvebeam.com/)
- [Examples](https://github.com/solvebeam/twinfield-php/tree/main/examples)
- [Changelog](https://github.com/solvebeam/twinfield-php/blob/main/CHANGELOG.md)

## Coming from `php-twinfield/twinfield`?

The new SDK is a new library with its own API, not a drop-in replacement. It needs PHP 8.3 or newer.

[`php-twinfield/twinfield`](https://github.com/php-twinfield/twinfield) stays available so existing projects keep working, but it gets no new features or fixes. Please open issues and pull requests in [solvebeam/twinfield-php](https://github.com/solvebeam/twinfield-php/issues).

Thanks to everyone who contributed to PHP Twinfield over the years.
